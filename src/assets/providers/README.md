# AI provider and model maker icons

`claude.svg` and `gemini.svg` come from [Simple Icons](https://simpleicons.org) 16.35.0 (`icons/claude.svg` and `icons/googlegemini.svg`), released under CC0, with the brand colour Simple Icons lists for each added as the fill (Claude `#D97757`, Google Gemini `#8E75B2`).

The others come from [Lobe Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.95.1, MIT licence), with the sizing attributes removed:

| File | Lobe Icons source | Shown for |
| :--- | :--- | :--- |
| `openai.svg` | `openai.svg` (one colour, filled `#141414`) | OpenAI generals, and gpt-oss on OpenRouter |
| `openrouter.svg` | `openrouter.svg` (one colour, filled `#141414`) | An OpenRouter model whose maker the game does not know |
| `meta.svg` | `meta-color.svg` | Llama and Muse models |
| `zai.svg` | `zai.svg` (one colour, filled `#141414`) | GLM |
| `gemma.svg` | `gemma-color.svg` | Gemma |
| `deepseek.svg` | `deepseek-color.svg` | DeepSeek |

| `mistral.svg` | `mistral-color.svg` | Mistral |

The one-colour marks are drawn on a small white disc so they also show on dark buttons.

The names and logos are trademarks of their owners (Anthropic, Google, OpenAI, OpenRouter, Meta, Z.ai, DeepSeek, Alibaba, Moonshot AI, Mistral AI, NVIDIA, xAI and MiniMax). The game shows them only to identify which provider's or maker's model is commanding an army.
